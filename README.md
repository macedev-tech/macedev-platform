# MaceDev Platform

Plataforma de estudos para desenvolvimento de software moderno utilizando Go, Python, Docker, Inteligência Artificial e Cloud.

## Objetivo

Este projeto será desenvolvido passo a passo com foco em:

- Aprender Go (Golang)
- Aprender Python
- Dominar Git e GitHub
- Trabalhar com Docker
- Integrar com a API da OpenAI
- Implantar aplicações em Cloud
- Construir um ambiente de desenvolvimento profissional
